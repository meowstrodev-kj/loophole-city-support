Loophole City / 루프홀 시티

Game information

An offline law-puzzle game in English and Korean. Investigate cases, draft bylaws, and close Kim Fox’s loopholes while protecting the citizens’ daily routines.

This site provides privacy and support information. The game is distributed as an app; there is no public web game.

게임 안내

한국어와 영어로 즐기는 오프라인 조례 퍼즐 게임입니다. 사건을 조사하고 조례를 작성해 시민의 일상을 지키며 김여우의 꼼수를 막으세요.

이 사이트는 개인정보 처리방침과 지원 정보를 제공합니다. 게임은 앱으로 배포하며 공개 웹 게임은 없습니다.
